# Security Policy

Agent Skill Kit contains guidance that may be used in software, automation, and security workflows. The repository is intended for authorized defensive work. It must not be used to gain unauthorized access, steal credentials, deploy malware, evade detection, bypass safeguards, or damage systems.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability involving this repository or its automation. Use GitHub’s private vulnerability reporting feature if enabled, or contact the repository maintainer privately through the account associated with this project. Include the affected path or commit, impact, reproduction details that do not require destructive behavior, and a suggested mitigation if available.

If you discover that a skill contains unsafe instructions, exposed secrets, private information, malicious dependencies, or misleading high-risk guidance, report it privately and do not redistribute the affected content while the issue is being investigated.

## Scope

This policy covers repository content, validation scripts, workflows, release artifacts, and contribution processes. It does not guarantee the security of any external project that installs a skill. Users must review a skill, its source references, dependencies, tool permissions, and target environment before use.

## Maintainer response

Maintainers will acknowledge reports when practical, assess severity and exploitability, remove exposed secrets or unsafe content, publish a corrective change, and document the resolution without unnecessarily exposing sensitive details.
