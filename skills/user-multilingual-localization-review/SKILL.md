# Multilingual Localization Review

## Purpose and scope

Identify source and target locales, audience, content type, glossary, brand voice, variable syntax, legal or accessibility constraints, and whether review is linguistic, functional, or both.

## Workflow

Check translation fidelity and intent; verify terminology and placeholders; test plural, gender, date, time, number, currency, directionality, and text expansion; inspect truncation and layout; review alt text, labels, keyboard paths, and culturally unsafe phrasing; obtain qualified human review for high-impact content.

## Verification and quality checks

Compare source and target in context, run placeholder and locale tests, check visual rendering, verify glossary consistency, and record uncertainty where the source itself is ambiguous.

## Common errors

Common errors include literal translation, broken interpolation, untranslated fallback, incorrect plural rules, clipped UI, wrong locale formats, and machine output presented as final human review.

## Rules, safety, and non-goals

Do not expose personal data or use machine translation as a substitute for qualified review in legal, medical, safety, or accessibility-critical content. Do not invent sources, data, results, approvals, or completed actions. Preserve privacy and use the smallest relevant skill composition.

## Handoff

Return locale matrix, findings with source and target text, severity, suggested correction, visual/test evidence, glossary updates, and reviewer status.
