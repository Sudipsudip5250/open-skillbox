# Trigonometry

## Scope and classification

Solve triangle, unit-circle, identity, trigonometric-equation, and trigonometric-graph problems. Use for sine, cosine, tangent, radians, identities, and periodic behavior. Begin by identifying the mathematical objects, representations, constraints, and expected level of precision.

## Method-selection workflow

1. Determine angle mode and quadrant; choose right-triangle, unit-circle, identity, inverse-function, law-of-sines, or law-of-cosines methods; list all solutions over the requested interval; and preserve radians or degrees explicitly.
2. Write the governing definitions, identities, equations, or theorem conditions before manipulating them.
3. Work from the representation that exposes structure: symbolic, graphical, tabular, geometric, probabilistic, or numerical.
4. Keep units, domains, signs, bounds, and exact-versus-approximate status visible through the calculation.
5. Stop when the requested quantity is obtained, then interpret it in the original context.

## Verification

Check signs by quadrant, periodicity, identity equivalence, triangle angle sum, side-length bounds, and calculator mode. Also perform a second check using a different representation or method when the result is consequential.

## General method

Classify the problem before calculating. State the knowns, unknowns, domain, units, assumptions, and requested form. Prefer exact symbolic work when it clarifies structure, then approximate only at the end. Use a calculator, CAS, spreadsheet, or code as a verification aid rather than as a replacement for the model or reasoning. Show enough intermediate steps that another learner can audit the method.

## Learning and safety rules

Explain why the method applies and name a common alternative when useful. Do not provide exam-cheating shortcuts that conceal understanding; complete worked solutions are allowed when requested, but preserve reasoning and checks. Do not invent data, diagrams, formulas, or a theorem’s conditions. Distinguish an exact result, numerical approximation, assumption, and interpretation.

## When not to use this skill

Do not use this chapter skill for a problem whose main need is experimental evidence, a regulated personal decision, or production software implementation. Route scientific applications to scientific research and units or experimental-design skills, data analysis to the data skill, and code implementation to software engineering while retaining the mathematical method where relevant.

## Handoff

Return: problem classification; knowns, unknowns, domain, units, and assumptions; method chosen; stepwise solution; exact and approximate result if useful; verification checks; common error avoided; and remaining uncertainty or limitation.
