# Sources and design basis

Agent Skill Kit contains original, concise workflow guidance written for this repository. Some design patterns were informed by public skill collections and official documentation; this file records those sources so contributors can re-check version-sensitive details.

The project does not redistribute private account Knowledge, user preferences, repository-specific instructions, credentials, or internal research artifacts. Contributors remain responsible for checking the license and attribution requirements of any external text, code, examples, or assets they add.

## Skill and workflow sources

- [Vercel agent skills](https://github.com/vercel-labs/agent-skills) — frontend, browser, and agent workflow patterns.
- [obra/superpowers](https://github.com/obra/superpowers) — planning, debugging, testing, and software-workflow patterns.
- [VoltAgent awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) — discovery index for agent-skill ecosystems.
- [Google skills](https://github.com/google/skills) — official examples of technology-specific skill packaging.
- [K-Dense scientific agent skills](https://github.com/k-dense-ai/scientific-agent-skills) — research, reproducibility, and scientific workflow patterns.
- [CloudAI-X Three.js skills](https://github.com/cloudai-x/threejs-skills) — browser 3D workflow patterns.
- [Netresearch Docker development skill](https://github.com/netresearch/docker-development-skill) — container-development patterns.
