# Sources and design basis

Agent Skill Kit contains original, concise workflow guidance written for this repository. Some design patterns were informed by public skill collections and official documentation; this file records those sources so contributors can re-check version-sensitive details.

The project does not redistribute private account Knowledge, user preferences, repository-specific instructions, credentials, or internal research artifacts. Contributors remain responsible for checking the license and attribution requirements of any external text, code, examples, or assets they add.

## Version-sensitive guidance

Sources, platform requirements, package APIs, security recommendations, and legal or advertising policies can change. Re-check the authoritative source before relying on a skill for a production, financial, privacy, security, monetization, or platform-policy decision.


## Mathematics and education references

- [OpenStax Mathematics](https://openstax.org/subjects/math) — open textbooks and resources covering algebra, trigonometry, precalculus, calculus, statistics, and data science.
- [MIT OpenCourseWare Single Variable Calculus](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/) — independent-study calculus materials with lectures, worked examples, problems, and solutions.
- [MIT OpenCourseWare Multivariable Calculus](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/) — multivariable and vector-calculus course structure and problem-solving materials.
- [NIST Digital Library of Mathematical Functions](https://dlmf.nist.gov/) — authoritative reference for special functions, notation, numerical methods, and mathematical computation.

These sources inform original workflows only. The repository does not copy textbook passages, answer keys, or proprietary course content.
